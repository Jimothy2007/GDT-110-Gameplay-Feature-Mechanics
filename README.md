How to access the submissions:
- For the Word document, click the link to download it then open it in Word.
- For the Video presentation, click the link then watch the video through YouTube.
- For the GitHub repository, click the link to bring you to the repository. Then you will need to clone the repository to your computer. Once you do that, open Unity and select add a project from disk and select the repository. Make sure you are on the main branch and open the project.

About the prototype game mechanic:
- Use W/A/S/D to move around and use the mouse to move the camera.
- Press the spacebar to jump. Hold the space bar to jump higher.
- There are two walls and a cube at the end. You can run on the inside of the walls to reach the top of the cube.
- To wall run, walk against the wall. If you have troubles staying on the wall, try jumping into the wall. If you are facing the wall when you run into it, nothing will happen so be sure to run parallel to the wall.
- While wall running, keep holding the movement keys so you don't fall off the wall. When you are ready to get off the wall, hold jump and you will launch off of the wall. Try to transfer to the second wall and reach the top of the cube.
